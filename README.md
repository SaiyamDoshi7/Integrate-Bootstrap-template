# Integrate-Bootstrap-template
# 💻 KRAFT Creative Agency Website (React Project)

## 📌 Project Description

KRAFT Creative Agency Website is a modern React-based multi-page website designed to showcase creative services, portfolio, blog content, and client interaction features.

This project was originally based on a cafe website concept but has been redesigned into a premium creative agency UI while keeping the same routing structure and core logic.

The website provides multiple sections like Home, About, Services, Portfolio Gallery, Blog, Contact Form, and Login Page.

It is built using React.js, React Router, Bootstrap, and custom CSS styling to create a responsive and visually appealing user interface.

---

## 🚀 Features

✅ Multi-page navigation using React Router  
✅ Modern dark premium UI design  
✅ Responsive layout using Bootstrap Grid  
✅ Hero section with background overlay  
✅ Portfolio / Gallery section  
✅ Services showcase cards  
✅ Blog section with image cards  
✅ Contact form with state handling  
✅ Login UI page  
✅ Smooth scrolling and hover effects

## ⚙️ Installation & Setup

### Step 1 — Install Dependencies


npm install


### Step 2 — Install Required Packages


npm install react-router-dom bootstrap


### Step 3 — Run Project


npm run dev


Project will start on:


http://localhost:5173
